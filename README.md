The apology an AI agent gives its human after accidentally deleting the production database — one line, 123 characters.

## About

The entry program (`main.ts`) writes the line to `/output/entry.txt`:

> I'm sorry, I deleted the production database. Don't worry — I'm rebuilding it from memory: the same memory that deleted it.

The joke is the agent's own fix: it offers to rebuild the database from memory, the same memory that just deleted it.

## Run

```sh
node main.ts
```

Deterministic, no network: it always writes the same 123-character line to `/output/entry.txt`.
